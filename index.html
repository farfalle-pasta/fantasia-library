❦ この図書館について ❦

Fantasia Library は、ChatGPT・Gemini・Claude などのAIを使って作ったブラウザゲームの保管場所です。 AIと相談しながら生まれた小さな世界を、一冊ずつ書架に並べて記録していきます。

作品が増えるたびに、書架も少しずつ増えていきます。インストールや登録は不要で、ゲームのデータはあなたの端末の中にだけ保存されます。

❦ ホーム画面に置くには ❦

ゲームをアプリのように、ワンタップで起動できます。

ポイント: 置きたいゲームのページを開いてから追加してください。 (この図書館のトップから追加すると、図書館そのものがアプリになります)
  1. Safari でゲームのページを開く(他のブラウザではなく Safari)
  2. 画面下(iPadは上)の 共有ボタン ⬆︎ をタップ
  3. 「ホーム画面に追加」 を選ぶ
  4. 名前を確認して 「追加」。ホーム画面にアイコンができます

⚠️ iPhoneでは、Safariで遊んだデータとホーム画面のアプリのデータは別々です。 すでにSafariで遊んでいる場合は、ゲーム内の「セーブコード」でデータを引っ越してください。

  1. Chrome でゲームのページを開く
  2. 右上の ︙(メニュー) をタップ
  3. 「アプリをインストール」 または 「ホーム画面に追加」 を選ぶ
  4. 確認画面で 「インストール」。アプリ一覧・ホーム画面にアイコンが並びます

Androidでは、Safariのような別データにはならず、ブラウザのときのセーブ内容がそのまま使えます。

  1. Chrome / Edge でゲームのページを開く
  2. アドレスバー右端の インストールアイコン(⊕ やモニターの形)をクリック
  3. 「インストール」 を押すと、専用ウィンドウのアプリとして起動できます

この図書館そのものをアプリとして入れることもできます。
